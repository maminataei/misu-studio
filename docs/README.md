# Commerce Studio Documentation

## Authority

This directory is the implementation source of truth. Product documents define
observable behavior. Specifications define portable contracts. Architecture
defines ownership and runtime boundaries. Security and operations define safe
deployment. ADRs explain why durable choices were made.

## Normative vocabulary

- MUST and MUST NOT are release requirements.
- SHOULD and SHOULD NOT require recorded justification to violate.
- MAY describes supported optional behavior.
- Configurable behavior MUST identify its owning configuration and default.

Implementation code, examples, and UI copy cannot override these documents.
