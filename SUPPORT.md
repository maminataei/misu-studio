# Support

## Community support

Use repository discussions for usage questions and public issues for verified
bugs and feature proposals. Search existing material first and provide version,
deployment method, logs with secrets removed, and reproducible steps.

## Operational incidents

Self-hosted operators own incident response. The runbooks document degraded
preview, worker, storage, identity, publication, and webhook behavior. A
storefront renderer MUST keep serving its last verified map when Studio is
unavailable.

## Exclusions

Public support channels must not receive credentials, customer records, private
assets, unpublished maps, or security reports.
